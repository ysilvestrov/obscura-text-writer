# Перевірка першого етапу

Дата: 19 жовтня 2026 року. Гілка: `feat/automatic-evaluator`. Базовий коміт: `c3fa538`.

## Що реалізовано

Автономний оцінювач із чотирма режимами команд: перевірка окремого входу, dry-run, порівняння звітів та калібрування. Режими аналізу: сцена, редактура, твір. Провайдери: локальний OpenAI-сумісний API, OpenRouter та окремий Codex CLI для тестування промпту. Збереження джерел, цитат, оцінок, промпту, сирої відповіді й доступного usage; контрольний набір із десяти прикладів.

Це перший етап застосунку, не готовий генератор оповідань. Вебінтерфейс, SQLite, пам’ять твору й чотири етапи генерації залишаються наступними роботами.

## Докази перевірки

- Повний офлайн-набір: 65 тестів, усі пройдені на Python 3.12.14 / Windows.
- `pip check`: залежності узгоджені.
- Пакет встановлено editable; help працює з іншого робочого каталогу, у тому числі зі старим кодуванням cp1250.
- Dry-run показує склад документів та обсяг; повний набір калібрування з трьома повторами показує 30 викликів.
- Чотири реальні виклики Codex CLI дали структуровані відповіді. Виявлено навмисну помилку узгодження та зміну віку після редактури; на двох контрольних текстах findings не було.
- Реальні виклики локального API й OpenRouter не виконувалися. Їхній протокол та обробку помилок перевірено через HTTP MockTransport.
- Повне калібрування на явно названій моделі не виконано. Жоден профіль не переведено в calibrated. Модельне використання не оголошується безкоштовним або безлімітним.

## Незалежний огляд і виправлення

Виконано один незалежний огляд усієї гілки окремим агентом; він знайшов чотири суттєві проблеми та два дрібні зауваження. Виправлення перевірено регресійними тестами, що спочатку відтворили дефект, а після зміни пройшли; весь набір лишився зеленим.

1. Цитати, що перекриваються, більше не рахуються як дві незалежні опори. Дві різні неперекривні ділянки одного документа залишаються дозволеними.
2. Калібрування відхиляє інший канон, застарілий fingerprint, змішані конфігурації та повторне використання run_id.
3. Вибрана підмножина прикладів не може пройти калібрування за весь контрольний набір.
4. Часткова API-відповідь лишається помилкою, але її текст, usage та тривалість зберігаються.
5. Зауваження щодо розмітки переглянуто як суттєве: неправильна precision впливає на вибір моделі. Додано allowed_findings для додаткового коректного висновку про порушення канону.

Відкладене дрібне зауваження: score_ranges дорівнює 0 при одному доступному спостереженні; кількість повторів і null у verdict_changed показують, що стабільність не підтверджена. Це не дозволяє отримати calibrated чи eligible.

## Рішення під час виконання

- За вибором користувача робота виконувалася в окремій гілці поточної папки, без worktree. Компроміс: немає паралельної копії checkout.
- Bash-допоміжні скрипти навички замінено еквівалентним журналом кроків у `.superpowers/sdd/2026-10-19-automatic-evaluator/progress.md`. Компроміс: докази RED→GREEN та коміти зіставлялися вручну.
- Codex CLI додано за прямою пропозицією користувача як адаптер тестування промпту. Компроміс: параметри й модель потрібно калібрувати окремо від API-провайдерів.
- OpenAI SDK обмежено основною версією 2 для запланованого httpx-адаптера; точні залежності зафіксовано. Компроміс: нову основну версію доведеться перевіряти окремим оновленням.
- Текстові limitations є примітками; неповноту визначають структуровані критерії та coverage. Інакше застереження про відсутні майбутні сцени робило кожну перевірку окремої сцени неповною. Компроміс: хибний самоопис checked потребує виявлення калібруванням.
- Початкове рішення лише описати занижену precision пілоту замінено виправленням розмітки та метрики після огляду. Компроміс: контрольні очікування потребують явного опису додаткових коректних проявів дефекту.

## Межі висновків огляду

Реальна літературна надійність і повне калібрування залишаються неперевіреними. Збіг цитат не доводить правильності семантичного висновку; це перевіряється контрольним набором і пізнішою ручною оцінкою. Codex CLI не гарантує паритету temperature/max_tokens з API. Не змінювалися генерація, сховище, інтерфейс, хостинг або Cloudflare.
