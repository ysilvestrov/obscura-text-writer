# Коротка редактура → diff → класифікація — 21.10.2026

## Мета й погоджений обсяг

Власник погодив наступний дослідницький тест короткого уривка й запропонував альтернативу: попросити модель повернути відредагований текст без схеми, обчислити зміни скриптом, класифікувати їх окремим викликом. Зміни робочого workflow цим тестом не погоджувалися і не виконувалися.

Використано залишок попереднього ліміту $0,25, у тому самому ізольованому бюджетному scope; попередні невизначені витрати й резерви не звільнялися. Шість нових викликів без повторів: патчі, суцільна редактура та класифікація для двох редакторів. Робоче оповідання, налаштування ролей і голови версій не змінені.

## Метод

- Один безперервний початковий уривок попередньої чернетки: 1517 символів, 18 непорожніх рядків; hash і текст у приватному manifest/original.
- Редактори: `qwen-3-8-27b` та `abliteration-abliterated-model-large-v2`; обидві моделі проходять штатну перевірку Venice `uncensored=true`, доступності та можливостей.
- Температура 0,2; `max_tokens=4096`. Qwen: `reasoning.enabled=false`. Large V2: `reasoning.effort=low` — експериментальний wire-параметр; штатний RoleSettings наразі не має окремого поля effort.
- Спільна коротка інструкція про мовне редагування і збереження змісту. Відрізняється контракт відповіді: CopyEdits/JSON Schema проти лише відредагованої прози, без response_format, JSON і номерів фрагментів.
- JSON-патчі перевіряються штатними parser/guards; не ремонтуються.
- Для прози `difflib.SequenceMatcher(autojunk=False)` порівнює слова, пробіли й пунктуацію. Кожна операція містить точні початкові start/end/original/replacement. Застосування операцій у зворотному порядку MUST точно відтворити отриману відповідь; це перевірено assert для кожного результату. Окремо перевіряються збереження чисел і заперечень, але ці перевірки не доводять семантичної еквівалентності.
- Класифікацію виконує окремий виклик Qwen з оригіналом, новим текстом і вже обчисленим diff. Schema: індекс, категорія, assessment, коротке пояснення. Після відповіді перевіряється повне однократне покриття індексів. Класифікатор не створює й не змінює самі заміни.
- Запити нестримінгові з мережевим timeout=90 с та SDK max_retries=0. Усі шість завершилися нормально, без відмов.

Це не чистий тест «лише схема»: відрізняється саме завдання формування відповіді — готова проза проти локальних патчів. Порівняно з попередньою серією також скорочені контекст і промпт. Висновки про кожен окремий чинник мають ці обмеження.

Три контрольні випадки — відмінок статичного розташування, нормативне написання назви частини тіла, нормативна словоформа минулого часу. Це маленька контрольна підмножина, а не повний еталон усіх помилок уривка. Large у режимі прози виправляє 3/3, у режимі патчів — 1/3; Qwen — 1/3 в обох режимах.

Для Large сім технічних ділянок diff не дорівнюють семи незалежним літературним правкам: дві сусідні операції разом інтерпретують рух одягу. Числа й заперечення в обох суцільних відповідях збережені. Довжина Large — 99,54% оригіналу; Qwen — 100,07%. Ці метрики не замінюють аналіз змісту.

Large без схеми: 58,23 с; usage — 733 вхідні, 944 вихідні токени, із них reasoning=360. Вартість редактури $0,006919; класифікації $0,0019419; разом $0,0088609. Схемні патчі Large: 17,50 с; usage повідомляє reasoning=0. Запит effort=low збережений, але нуль у telemetry одного виклику не підтверджує загальну можливість вимкнути reasoning цієї моделі.

## Надійність класифікатора

Обидві відповіді Qwen пройшли структурну перевірку й покрили всі індекси. Однак:

- для однакової граматичної правки в одному виклику він назвав неправильний відмінок у поясненні;
- схвалив усі зміни Large як improvement, зокрема вилучення напрямку руху; це треба позначати як зміну змісту/авторське рішення, а не безумовно безпечну стилістику;
- подекуди категорія суперечить його ж поясненню; є недостовірне мовне пояснення.

Тому класифікація залишається консультативною. Самозвіт моделі не є доказом якості або дозволом на автоматичне прийняття. Окремий ручний перегляд збережений у приватному `manual-review.json`; індекси 3–4 Large позначені needs_review/meaning.
