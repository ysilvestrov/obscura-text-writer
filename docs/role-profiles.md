# Комплекти моделей і налаштувань

У налаштуваннях оповідання блок **«Збережені комплекти моделей»** переносить чотири ролі — планувальника, письменника, редактора й пам’ять — разом із параметрами та промптами. За вибором можна додати Evaluator. Стиль письма й авторські матеріали до комплекту не входять.

## Зберегти та повторно використати

1. Налаштуйте й збережіть усі чотири ролі звичайними формами. Комплект не бере незбережені правки.
2. Розкрийте «Зберегти поточні налаштування або імпортувати комплект», задайте назву й натисніть «Зберегти комплект».
3. У новому оповіданні виберіть комплект і конкретну версію, натисніть «Переглянути комплект». Перевірте моделі, ліміти й промпти; повний JSON доступний у «Усі параметри та промпти».
4. Натисніть «Застосувати до твору». Після підтвердження сторінка перезавантажиться. Незбережені зміни форм будуть втрачені; збережіть їх перед застосуванням, якщо вони потрібні.

Якщо ви зміните вибір або вручну відредагуєте форму, потрібно переглянути комплект знову. Конфлікт ревізій означає, що твір змінився після preview: повторіть перегляд. Часткового застосування ролей немає.

Для наступної версії налаштуйте ролі в оповіданні, виберіть актуальну версію потрібного комплекту та позначте «Зберегти нову версію вибраного комплекту». Попередні версії й налаштування інших оповідань залишаться незмінними. Однакові назви дозволені; імпорт створює окремий профіль.

## Evaluator та ключі

Прапорець «Додати Evaluator» включає збережені налаштування й політику, але **не допуск калібрування**. Без цього прапорця Evaluator цільового твору залишається незмінним. `report` та `off` можна переносити; `pause_on_failure` без калібрування блокує перегляд/застосування без прихованої заміни на `report`. Для переносимого комплекту збережіть Evaluator у `report` або `off`; допуск налаштуйте окремо за процедурою калібрування. Блокування після відмови для цільового твору не скидається.

Файл JSON не містить значень API-ключів; він зберігає лише назви змінних середовища, наприклад `VENICE_API_KEY`. На іншому комп’ютері ключ потрібно окремо додати до `.env`. Не вставляйте ключ у назву моделі, промпт чи інші довільні текстові поля: ці тексти входять до експорту. Власний `codex_command` у переносимому профілі заборонений; дозволено тільки стандартний `codex`.

Кнопки «Експортувати JSON» та вибір JSON-файла працюють без модельних викликів. Максимум — 2 MiB UTF-8. Імпорт перевіряє схему, чотири ролі та контракти промптів; невідомі поля, чужі prompt UUID й фальшиве калібрування відхиляються. Власні промпти копіюються як нові версії цільового твору. Стандартні промпти беруться з чинної версії застосунку.

Застосування не перериває активний виклик. Наступний етап використовує нові параметри. Жодна дія з комплектами не запускає генерацію або платний виклик сама по собі.
