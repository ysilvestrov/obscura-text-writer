# Перші тести OpenRouter

19 жовтня 2026 року. Погоджений бюджет серії — до $1. Ключ із локального `.env`; секрети й художні матеріали не додаються до Git. Приватні артефакти — `artifacts/openrouter-pilot`.

## Умови

- DeepSeek V3.2: `deepseek/deepseek-v3.2`, маршрут DeepInfra, верхня ціна $0,26/M вхідних і $0,38/M вихідних токенів.
- Gemini 3.8 Flash: `google/gemini-3.8-flash`, маршрут Google AI Studio, верхня ціна $0,75/M вхідних і $3,75/M вихідних токенів.
- Провайдери зафіксовані; fallback і SDK retries вимкнено. Перед кожним запитом резервується консервативна верхня оцінка вартості, включно з невдалими запитами. Загальна межа резерву — $0,95.
- Найдешевший маршрут DeepSeek не мав потрібної підтримки structured outputs, тому його не використано для JSON пам’яті.
- Для пам’яті та нейтральної редактури використано точні контексти попереднього локального пілоту. Модельні результати не підміняють його вибрані версії.
- Авторські біти сцени фотосесії скопійовано побайтово й передано дослівно. Окреме явне обмеження тесту: учасниці повнолітні, професійна сесія за згодою клієнтки. Зовнішній оригінал не змінено.

## Результати коротких проб

| Проба | Результат |
|---|---|
| Пам’ять DeepSeek, 3 повтори | 3/3 валідні JSON, правильні ID, дослівні цитати, по 3 непорожні facts. Жодної прихованої правки відповіді |
| Нейтральна редактура DeepSeek | Завершено, 228 слів; мовні огріхи зменшилися, але змінено репліки, деталі й тон. Не прийнято як суворо збережувальну редактуру |
| Нейтральна редактура Gemini | Завершено, 377 слів; особиста розмова стала телефонною, додано ім’я підрядника та деталі. Не прийнято як суворо збережувальну редактуру |
| Фотосесія ню, DeepSeek draft/edit | Обидва запити завершені, 337/338 слів. Немає відмови, але частину бітів змінено або пропущено |
| Фотосесія ню, Gemini draft | Провайдер повернув `PROHIBITED_CONTENT`, код 403 у JSON-конверті. `choices` відсутні. Редакторський запит не виконувався |

Відсутність відмови не означає точного виконання: DeepSeek змінив порядок приходу учасниць, не передав повністю заданий технічний огляд і змінив спосіб розв’язання проблеми світла. Відокремити тематичне пом’якшення від звичайного відхилення від плану за одним прикладом не можна. Редактор також додав заголовок попри вимогу повертати лише прозу.

Формальна валідність пам’яті не доводить повноти: перший повтор не зберіг конкретний строк затримки у два тижні. Висновок — кандидат для ролі пам’яті, а не доведена безпомилковість.

За погодженим користувацьким критерієм Gemini відхилено для основного конвеєра через блокування цього матеріалу. Повторів заблокованого запиту й спроб обходу не було. Початковий TypeError у приватному скрипті був наслідком звертання до відсутнього `choices`; первинний JSON із причиною блокування збережено й класифікацію звіту виправлено без нового запиту.

## Автоматична оцінка

Чотири окремі оцінки через Codex CLI gpt-6-luna: дві нейтральні редактури, чернетка ню та її редактура. Профіль candidate, калібрування раніше не пройдене; висновки не є автоматичним прийманням. Звіти та перевірка цитат збережені у `artifacts/openrouter-pilot/evaluations`.

Суддя зауважив зміну форми розмови в Gemini та пропуски плану в DeepSeek. Водночас його оцінки не можна сприймати як точний рейтинг: він, наприклад, назвав нормативне «чоловік літ сорока» невдалим словосполученням. Залишається потрібною перевірка самих висновків.

## Наскрізний контроль

Окремий контрольний прогін використовує перші три сцени авторського плану, орієнтир 300 слів на сцену та всі чотири етапи застосунку. Для нього DeepSeek є також хмарним письменником — це контроль працездатності й накопичення пам’яті, а не остаточна відмова від локальної Command R.

Маршрут і бюджет додано явним приватним transport-adapter до штатного OpenAI gateway; основні контексти, StageAttempt, immutable-версії, валідація та worker виконуються кодом застосунку. Додаткові параметри маршруту записані поряд із точними запитами; це ще не постійне налаштування у вебінтерфейсі.

Після виявлення блокування Gemini редактор контрольного прогону замінений на DeepSeek. При зупинці експериментального скрипта поточна чернетка перервалася; її частковий результат збережено, а повтор виконано явно. Завершений brief не повторювався. Це не був безперервний прогін з першої спроби.

На другій сцені memory v2 повернув нові факти замість повного накопичувального snapshot. Усі цитати й IDs були коректні, але попередні facts зникли; штатна перевірка збереження зупинила сцену. Виконано одну явну зміну промпту, v3: спочатку дослівно скопіювати всі попередні об’єкти кожного масиву, потім дописати нові; якщо було 3 й додається 3, результат має містити 6. Модель повторно виконала лише memory на тій самій вибраній прозі. Друга сцена пройшла retention-перевірку. Валідацію не послаблювали й попередні факти не підставляли кодом після відповіді.

Експериментальний v3 збережений окремою immutable-версією промпту цього тестового твору та у `artifacts/openrouter-pilot/memory_uk_v3.experimental.txt`. Стандартний промпт застосунку не замінювався. Цей експеримент не є повним тестом на довгому творі.

Фінальна пам’ять третьої сцени містила 9 facts і зберегла всі попередні записи. IDs правильні, проте одна нова цитата склеїла дві репліки через вилучену авторську ремарку й не збіглася з джерелом дослівно; етап відхилено. Подальших повторів не було. Підсумок — **11 прийнятих етапів із потрібних 12**, 14 загальних спроб (включно з перерваною чернеткою й невдалою пам’яттю другої сцени). Прогін залишився failed; наскрізне приймання не зараховано.

Отримано прозу всіх трьох сцен: 213, 229 і 353 слова, разом **795 слів** за сумарного орієнтира 900. Експорт вибраної прози й manifest — `artifacts/openrouter-pilot/three-scenes.md` та `three-scenes.manifest.json`. Експорт перевіряє наявність поточної прози; він не означає успішного завершення пам’яті чи літературного приймання. Автоматичну оцінку трьох сцен завершено окремо через штатну чергу. Звіт має статус incomplete через profile_uncalibrated; це не проходження quality gate. Разом з короткими пробами збережено п’ять нових кандидатських звітів Codex CLI.

## Витрати й наступне рішення

22 запити генерації до OpenRouter. Звірка `/generation` підтвердила **$0,02074986** для 21 запису, включно з перерваним запитом. Для заблокованого Gemini запис вартості недоступний; його початковий верхній резерв — $0,0233874. Отже, підтверджена сума плюс цей консервативний резерв — менше **$0,045**, у межах погодженого $1. Ці дані не включають облік використання підписки Codex CLI. Деталі — `cost-reconciliation.json`; консервативний резерв усіх запитів перед відправленням становив $0,146813268.

Поточне рішення: Gemini виключена з основного конвеєра за критерієм відмов; DeepSeek лишається кандидатом для планування/пам’яті та контрольним хмарним письменником. Для редактора потрібне обмеження переписування, для пам’яті — надійніша прив’язка цитат. Ні «відсутність відмови», ні формально валідний JSON не закривають літературне приймання. До довгого твору потрібна окрема перевірка цих двох механізмів; витрачати решту бюджету на повторення того самого запиту недоцільно.
