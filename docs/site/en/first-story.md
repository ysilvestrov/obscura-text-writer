# Your first story

Before you start, [install the application and set up the models](install.md#models).

## Create a story

In the library enter the **New story title**, a target word count and the **Story language**, choose **Who writes the texts**, then press **Create story**. The language can be changed until a model has produced any material in the story.

**Who writes the texts** is **Obscura writes** by default: Obscura models write the texts, and a chat client over MCP only helps. Choose **The chat writes** if the chat itself will write the texts ([Chat clients (MCP)](mcp.md)). You can change the mode at any time in the story settings, **Writing** section; texts already written do not change.

## Add an outline and characters

In the scene list expand **Add materials**. Download the **Outline with timing (.md)** and **Characters (.md)** templates, fill them in with a text editor and import them. The application accepts UTF-8 TXT or Markdown. Importing again only adds new scenes and character cards.

You can also start without files: **Add scene** in the top row creates a scene with an outline skeleton (all its fields are empty in the first scene), and **Characters** opens the character cards.

Review the proposed scenes and participants before you run a model.

## Work through a scene in stages

Every scene has six tabs: **Outline → Brief → Draft → Editing → Prose → Memory**. A tab only opens the material; the primary button above the text starts the action.

1. **Brief.** The planner drafts a brief for the scene. Review and edit it if needed, then **Accept brief**.
2. **Draft.** The writer writes the text from the brief. You can edit it by hand; **Save** creates a new version without erasing earlier ones.
3. **Editing.** The editor suggests sentence-level changes. Pick the ones you want and accept the assembled text.
4. **Prose.** The accepted text of the scene. This is what goes into the export.
5. **Memory.** The memory model records what happened in the scene, with references to quotations. Later scenes rely on this record.

Before you press it, the primary button shows the model and the maximum number of calls; hover over it or reach it with Tab to see details and warnings.

## Follow the run

The status row above the text shows the scene status and the run progress, along with pause and cancel buttons. **Run options** holds the limit for the next run. Closing the tab does not cancel the work; cancelling does not guarantee the provider stops at once.

## Story actions

Everything that concerns the whole story lives in the **☰ Story actions** menu next to the title: **Book revision**, **Card and publication**, **Export…**, the budget and rename. Export to Markdown, TXT, FB2, EPUB or PDF is available as soon as scenes have accepted text.
