# Obscura Text Writer

Obscura is a local application for writing prose from your own outline. You work through the story scene by scene, and four model roles (planner, writer, editor and memory) help you draft a brief, write a draft, edit it and remember what happened.

The application runs on your computer. Stories are stored locally; a cloud provider, if you choose one, receives only the context of the action you start.

## Where to start

1. [Installation and launch](install.md): what you need, how to install and where your data lives.
2. [Your first story](first-story.md): from an empty library to the first finished scene.

## Good to know

- The model helps, but it does not guarantee literary quality. The author checks the final text.
- Cloud model calls may cost money. Before each run you see the model and the maximum number of calls, and you can set a budget in the settings.
- The application is meant for a single local user and has no password sign-in.
