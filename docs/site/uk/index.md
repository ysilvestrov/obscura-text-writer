# Obscura Text Writer

Obscura — локальний застосунок для письма прози за вашим планом. Ви ведете твір сцена за сценою, а чотири модельні ролі (планувальник, письменник, редактор і пам’ять) допомагають скласти завдання, написати чернетку, відредагувати її й запам’ятати, що сталося.

Застосунок працює на вашому комп’ютері. Твори зберігаються локально; хмарний провайдер, якщо ви його обрали, отримує лише контекст запущеної дії.

## З чого почати

1. [Встановлення й запуск](install.md): що потрібно, як встановити й де зберігаються дані.
2. [Перший твір](first-story.md): від порожньої бібліотеки до першої готової сцени.

## Що варто знати заздалегідь

- Модель допомагає, але не гарантує літературної якості. Остаточний текст перевіряє автор.
- Виклики хмарних моделей можуть бути платними. Перед кожним запуском видно модель і максимальну кількість викликів, а в налаштуваннях можна задати бюджет.
- Застосунок призначений для одного локального користувача й не має входу за паролем.
