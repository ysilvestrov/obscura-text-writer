# Поширені проблеми

## Запуск

| Що бачите | Що зробити |
|---|---|
| PowerShell не запускає `start.ps1` | Скористайтеся прямою командою запуску з розділу [Встановлення](install.md#запуск). |
| Порт уже зайнятий | Запустіть з іншим портом, наприклад `-Port 8770`. |
| «Цей каталог даних уже відкрито іншим виконавцем» | Інший сервер уже працює з цим каталогом. Закрийте його вікно PowerShell або вкажіть інший каталог даних. |
| Після оновлення сторінка поводиться дивно | Збережіть правки, перезапустіть сервер і оновіть вкладку. |

## Генерація не починається

| Що бачите | Що зробити |
|---|---|
| Просить задати віковий рейтинг | Задайте рейтинг у налаштуваннях твору, розділ **Письмо**. Див. [Віковий рейтинг](content-rating.md). |
| Блокування через вік персонажів | Допишіть `Вік:` у картку, приберіть персонажа зі складу сцени або змініть рейтинг сцени. Див. [Вік персонажів](content-rating.md#вік-персонажів). |
| «Спершу задайте явний ліміт бюджету» | Задайте загальний ліміт у **Бюджет викликів**. Див. [Бюджет викликів](models.md#бюджет-викликів). |
| «Немає чинного тарифу» | Натисніть **Оновити з каталогу** або збережіть ручний тариф. |
| «Недостатньо бюджету…» | Збільште загальний ліміт або ліміт запуску. Резерв консервативний і враховує повну відповідь. |
| Помилка ключа чи автентифікації | Перевірте ключ у `.env` і перезапустіть сервер. |
| Запит не вміщається в контекст | Скоротіть матеріали, зменшіть резерв відповіді або виберіть модель із більшим реальним контекстом. Текст приховано не обрізається. |

## Під час роботи

| Що бачите | Що зробити |
|---|---|
| Модель відмовилася | Автоматичного повтору немає. Змініть завдання чи модель і запустіть етап знову. |
| Запуск перервано після збою чи закриття сервера | Незавершений запуск стає перерваним. Продовжте його явно; повторний виклик хмарної моделі може бути платним. |
| Матеріал позначено застарілим | Джерела змінилися. Згенеруйте його заново або в історії версій натисніть **Переглянути й прийняти текст**, а потім **Продовжити після прийнятого етапу**. |
| «Змінено в іншій вкладці» | Ваші правки лишаються у формі. Оновіть дані й повторіть дію. |
| Витрата «потребує звірки» | Після збою вартість невідома. Звірте суму в **Історія викликів і звірка**, коли запуск завершено. |

## Експорт

| Що бачите | Що зробити |
|---|---|
| FB2 просить автора чи жанр | Заповніть їх у картці публікації й натисніть **Зберегти картку**. |
| Потрібні додаткові залежності publication | Встановіть їх командою з розділу [Встановлення](install.md#встановлення-з-вихідного-коду). |
| Експорт просить дозволу | Деякі сцени неперевірені чи без прози. Дозвольте неповний експорт або спершу завершіть сцени. |

## Резервні копії

Перед оновленням або експериментами зробіть резервну копію за інструкцією в розділі [Резервне копіювання](install.md#резервне-копіювання). Відновлення створює новий каталог і нічого не перезаписує. Якщо резервування чи відновлення перервалося, не використовуйте неповний каталог: повторіть дію з перевіреної копії в новий каталог.
