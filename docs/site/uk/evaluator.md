# Оцінювач

Оцінювач — окрема модель, яка перевіряє готову сцену чи твір за критеріями: мова, узгодженість із планом і попередніми сценами, редактура. Він не змінює текст, а створює звіт із цитатами. Оцінка моделі — допоміжний інструмент, а не літературний вирок.

## Налаштування

1. Відкрийте налаштування твору → **Оцінювач**.
2. Вкажіть провайдера, модель, контекст, резерв відповіді, температуру й ліміт входу так само, як для [інших ролей](models.md#налаштування-ролі).
3. Натисніть **Зберегти: Оцінювач**.
4. Позначте **Увімкнути оцінювач · зберігається одразу**. Галочка використовує вже збережену модель, тому новий оцінювач спершу збережіть.

Комплект моделей оцінювача автоматично не налаштовує. **Критерії та пороги** доступні в додатковій формі. **Технічний JSON** — необов’язковий режим для досвідчених: зміни в ньому застосовуються лише кнопкою Apply.

Перевірена початкова конфігурація для режиму «лише звіт»: Venice, модель `qwen-3-8-27b`, контекст 262144, резерв відповіді 3000, температура 0,1, режим відповіді «схема в промпті» (`prompt_json`), вимкнений thinking. Це приклад, а не гарантія для будь-якого тексту.

## Режими

- **Вимкнено** — оцінювач не викликається.
- **Лише звіт** — звіти й попередження; проблема чи помилка не зупиняє генерацію. Починайте з цього режиму.
- **Пауза при проблемі** — генерація зупиняється, якщо оцінка не пройдена, неповна чи завершилася помилкою. Режим доступний лише для відкаліброваного профілю; без калібрування його не ввімкнути.

Новий профіль дає попередні висновки зі статусом «неповно», навіть коли попередній вердикт позитивний. Це очікувано, а не збій.

## Запуск

На робочій сторінці натисніть **Оцінити сцену** або **Оцінити твір** і підтвердьте запуск. Для англійської прози оцінювання поки недоступне (див. [Мова твору](story-language.md#що-інакше-для-англійської-прози)). Оцінювання йде через спільну чергу разом з іншими етапами. Звіт показує висновки, цитати й покриття. Збіг цитати доводить, що фрагмент є в тексті, але не те, що оцінювач правильно його зрозумів.

## Помилки

| Що бачите | Що перевірити |
|---|---|
| Немає ключа / помилка автентифікації | Ключ у `.env` і назву змінної в налаштуваннях |
| Квота / ліміт частоти | Баланс або обмеження частоти в провайдера |
| Тайм-аут / з’єднання | Доступність API й час очікування |
| Неповна відповідь | Резерв відповіді й підтримку формату моделлю |
| Бракує контексту | Реальний контекст моделі, резерв відповіді й розмір запиту |
| Відмова | Модель відмовилася оцінювати текст; це не технічна помилка |

Після відмови моделі через зміст оцінювач **блокується для цього твору**: наступні сцени йому не надсилаються. Зміна промпту, температури чи перезапуск блокування не знімають. Виберіть іншу модель або вимкніть оцінювача. Технічні помилки блокування не створюють, а автоматичних повторів немає.
