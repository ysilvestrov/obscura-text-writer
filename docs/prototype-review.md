# Незалежний огляд прототипу

Оглянуто всю реалізацію від `6542e77` до `48a7063`, окремим агентом із чистим контекстом. Перший запуск огляду на Astra не почав роботу через ліміт моделі; огляд завершив доступний Sol. Результат — сім суттєвих findings, без виявленого критичного витоку ключів.

| Finding | Виправлення та regression-доказ |
|---|---|
| Revision редактора оновлювався без відповідного тексту | Буфер зберігає revision завантаженої версії; Node-тест refresh відтворив небезпечне просування revision до виправлення |
| Набране під час pending save позначалося збереженим | Спільний saveBuffer порівнює відправлений і поточний текст, блокує паралельні saves; Node-тести plan/prose спершу падали, тепер проходять |
| Оцінювач не мав StageAttempt перед запитом | Збережені точні входи/спроба/partial/checkpoint кожного вікна; interrupted потребує явного повтору, завершені вікна повторно не надсилаються |
| Повторний імпорт персонажів не міняв revision та dependencies | Активне джерело публікується з metadata/revision/invalidation в одній транзакції; непублічний blob не стає контекстом; старий in-flight результат лишається альтернативою |
| Перебудова пам’яті прибирала обов’язковий перегляд прози | Memory completion зберігає needs_review; очистити його може нова редактура або явний вибір авторської прози; звичайний експорт лишається заблокованим |
| Нестріктна JSON Schema надсилалася як strict | Рекурсивно required для всіх properties, additionalProperties=false, без defaults; виправлено перед новими локальними пробами |
| Промпт brief замінював prepare | Розділені version IDs й поля UI; незмінений стандартний промпт не перетворюється на override |

Додатково підвищено до функціональних вимог два зауваження: вступні глобальні вказівки плану тепер входять у versioned context; завдання доступне для ручного JSON-редагування, а суттєві зміни потребують окремого прийняття. Захист navigation/unload для dirty/pending буфера включено до виправлення втрати ручних правок.
