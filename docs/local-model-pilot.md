Завантаження/вивантаження звірено з [офіційним native REST API](https://lmstudio.ai/docs/developer/rest/unload).

Службовий stop — явний параметр конкретної ролі, збережений у manifest; для інших ролей/моделей за замовчуванням список порожній. Він не переписує промпт і не перетворює обірвану відповідь на успіх: повна відповідь усе ще вимагає справжнього `finish_reason=stop`, валідного JSON та точних джерел пам’яті. Невдалих відповідей не ремонтуємо приховано й не відправляємо автоматично до іншої моделі.

Реального твору 5000–15000 слів і авторського літературного приймання ще немає. Автоматичний оцінювач gpt-6-luna не пройшов калібрування, тому candidate-звіти не закривають цей критерій.
