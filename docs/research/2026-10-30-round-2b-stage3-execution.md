## Rulings щодо механічного фільтра

- Довжина — символи зміненого каналу: target для A/B/C/E; об’єднані передумови для D. Рамка в парі однакова. D додає одну окрему передумову пріоритету, target незмінний.
- Один фрагмент — одна зона редагування на рівні слів (`SequenceMatcher`, без autojunk); окремі зміни через незмінні слова — окремі зони. Для E дозволена одна замінена клауза. Це суворий фільтр, не доведення мінімальності змісту.
- Нормалізація 4-грам: Unicode, регістр, пунктуація; апострофи нормалізуються. Перевіряються всі передумови, включно з рамкою.
- Імена рамки задаються явно; вони мають бути в дозволеному списку персонажів та згадуватися поза рамкою. Це структурний контроль, не повноцінне автоматичне розпізнавання довільних імен.
- Усі чотири приклади одного шаблону розносяться в панелі. Seed і ключ зберігаються приватно до розмітки. Код генератора не містить реального gold; дані/ключ тимчасово ignored, manifest містить лише їхні SHA.
- Новий набір не передається іншому агенту або моделі. Незалежне code review може читати тільки механізм і синтетичні unit-fixtures.
