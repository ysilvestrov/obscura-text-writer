# Інсталятор (#30): рішення власника перед специфікацією

Дата: 2026-11-11. Мета документа: вибрати варіанти, з яких буде написана специфікація #30. Технічні питання (чим заморожувати Python, вікно чи іконка в треї) вирішуються в специфікації, тут — лише те, що залежить від власника: гроші, платформи, канали продажу.

Ціни взято з публічних джерел станом на листопад 2026 (посилання внизу). Частина джерел — сторінки перепродавців і порівняння конкурентів, тож перед оплатою їх треба звірити з офіційною сторінкою. Жодної платної дії цей документ не запускає.

## 1. Платформи першого релізу

| Варіант | Що дає | Ціна / обмеження |
|---|---|---|
| **A. Лише Windows** (рекомендую) | Один інсталятор, перевірений на твоїй машині; швидший перший реліз | Без додаткових витрат на платформу |
| B. Windows + macOS | Ширший ринок (частина письменників на Mac) | Apple Developer Program $99/рік для нотаризації; потрібен Mac для збирання й перевірки; приблизно подвоєне тестування |

macOS можна додати другим релізом: заморожений Python і Velopack працюють на обох платформах, тож архітектура не закриває цей шлях.

## 2. Підпис коду для Windows

Без підпису Windows показує «Невідомий видавець» і SmartScreen-попередження, а збірки PyInstaller частіше дають хибні спрацювання антивірусів. Для платного продукту це знижує довіру саме в момент встановлення.

| Варіант | Ціна | Плюси | Мінуси |
|---|---|---|---|
| A. Без підпису на старті | $0 | Нічого не купувати | Попередження SmartScreen і антивірусів на кожному встановленні; погано для продажів |
| **B. OV-сертифікат із хмарним ключем** (рекомендую для прямих продажів) | ≈ $220–440/рік (Sectigo — дешевше, DigiCert ≈ $439); з 2026 року строк сертифіката — до року | Підписаний інсталятор із твоїм іменем; працює з будь-якою країною | Репутацію SmartScreen OV набирає поступово з кількістю завантажень, тож перші тижні попередження ще можливе; ключ обов’язково в HSM/хмарі |
| C. Azure Artifact Signing | $9.99/міс (5 000 підписів) | Найдешевший підпис | Для фізичних осіб — лише США й Канада; організації — з переліку країн (ЄС, Велика Британія тощо). Оплата починається зі створення облікового запису, навіть якщо перевірку особи не пройдено |
| D. Microsoft Store (MSIX) | $0: реєстрація безкоштовна, Microsoft сам підписує MSIX-пакет | Немає витрат на сертифікат, довіра магазину, оновлення через Store | Перевірка застосунку магазином і ризик із контентною політикою через рівні рейтингу; потрібна збірка MSIX; для власних EXE/MSI Store підпис не робить |

B і D можна поєднати: прямий продаж підписаного інсталятора плюс Store як другий канал. Безкоштовна програма SignPath Foundation для відкритого коду нам, імовірно, недоступна: FSL не є ліцензією OSI.

## 3. Оновлення

| Варіант | Що дає | Ціна |
|---|---|---|
| **A. Автооновлення через Velopack** (рекомендую) | Застосунок сам пропонує оновлення й завантажує лише різницю; перед оновленням — обов’язковий `storygen backup`, бо оновлення може мігрувати базу | $0 (відкритий код); файли оновлень лежать на GitHub Releases або власному хостингу |
| B. Лише сповіщення «є нова версія» | Простіше; автор сам завантажує й ставить інсталятор | $0; автор може роками сидіти на старій версії |

Перевірка оновлень — єдиний мережевий запит поза провайдерами моделей; його буде явно описано, телеметрії немає.

## 4. Продаж і видача збірок

| Варіант | Комісія | Що бере на себе |
|---|---|---|
| **A. Lemon Squeezy або Paddle** (рекомендую) | ≈ 5% + $0.50 за продаж (джерела розходяться, у Lemon Squeezy є доплати за міжнародні платежі й PayPal) | Merchant of record: ПДВ/податки з покупців у різних країнах, рахунки, ліцензійні ключі, видача файлу |
| B. Gumroad | ≈ 10% | Простіше налаштувати; чи бере він на себе податки як merchant of record — джерела розходяться, треба перевірити |
| C. Microsoft Store | Залежить від моделі оплати; треба звірити актуальні умови | Тільки разом із варіантом 2D |

Окремо треба вирішити, чи перевіряє застосунок ліцензійний ключ:

- **Без перевірки в застосунку** (рекомендую на старті): код публічний (FSL), тож захист ключем легко обійти; люди платять за готову збірку, підпис і оновлення. Менше коду й менше ризику заблокувати чесного покупця.
- З ключем для оновлень: ключ потрібен лише щоб отримати оновлення. Можна додати пізніше, якщо побачимо масове поширення збірок.

## 5. Локальна модель

| Варіант | Що дає | Обсяг |
|---|---|---|
| **A. Без моделі в інсталяторі; майстер, що знаходить LM Studio чи Ollama** (рекомендую) | Інсталятор лишається маленьким; автор з LM Studio/Ollama підключається в кілька кліків | Невеликий |
| B. Вбудований `llama-server` із завантаженням моделі | «Один клік» без сторонніх програм | Великий: збірки під різні GPU, гігабайтні завантаження, підтримка; краще другою фазою |

## Рекомендований набір і витрати

- Windows; OV-сертифікат із хмарним ключем; Velopack; Lemon Squeezy або Paddle без перевірки ключа в застосунку; майстер для LM Studio/Ollama.
- Постійні витрати: ≈ $220–440/рік на сертифікат. Хостинг оновлень — GitHub Releases ($0). Комісія — лише з продажів.
- Найдешевший робочий варіант: Microsoft Store (MSIX) замість сертифіката — $0 постійних витрат, але з перевіркою магазином і ризиком через контентну політику.
