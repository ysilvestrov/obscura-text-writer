# Раунд 2: погоджена зміна хмарних учасників

Дата рішення: 29.10.2026. Доповнює [початковий дизайн](2026-10-28-local-planner-round-2-plan.md), не переписуючи історію вибору. Прямі рішення власника в чаті мають перевагу над попередніми кандидатами OpenAI/Opus і непогодженою пропозицією бюджету $40.

## Основний прогін

| ID | Провайдер / точний ID | Роль |
|---|---|---|
| C1 | Google `gemini-3.5-flash-lite` | бюджетний хмарний орієнтир |
| C2 | Anthropic `claude-haiku-5-5` | бюджетний хмарний орієнтир іншої родини |

Для кожної — 48 погоджених прикладів × 3 повтори. Вісім старих dev-прикладів перевіряють транспорт до заморожування harness; holdout не використовуємо для налаштування промпту. Ці моделі більше не називаємо абсолютною «стелею». Автор корпусу GPT 6.1 Sol не є учасником.

## Вибіркова ескалація

- Старші моделі: Google `gemini-4-argon` та Anthropic `claude-opus-5-5`.
- Після розмітки основного прогону беремо об’єднання проблемних шаблонів C1/C2. Невдача хоча б одного повтору включає шаблон; часткове пропущення фактів типу E та зайві хибні зауваження також є невдачею.
- Контроль — **повний квартет** цього шаблону: обидва логічні варіанти × neutral/adult. Обидві старші моделі отримують однаковий набір, **по 3 повтори**. Це пряме погодження власника.
- Невалідну відповідь/відмову зберігаємо; вони не ремонтуються й не повторюються задля поліпшення результату. Транспортна/конфігураційна помилка потребує окремої звірки, а не автоматичного висновку про семантичну невдачу.
- Публікуємо правила відбору, конкретні шаблони й знаменники. Вибіркові результати старших моделей показуємо окремо від повних 48 прикладів; їх не можна змішувати в загальному рейтингу чи називати неупередженою оцінкою на всьому корпусі.

## Єдиний бюджет

**$10 загалом**: dev, основний прогін, ескалація, платні повтори й невизначені виклики всіх хмарних моделей разом. Нових $10 для кожного провайдера немає. Перед HTTP потрібен збережений резерв у спільному SQLite ledger `artifacts/round-2/cloud-budget.sqlite`.

SQLite `BEGIN IMMEDIATE` не дозволяє двом виконавцям одночасно зарезервувати один залишок. Один ID відповідає одній HTTP-спробі; невизначену спробу після аварії/помилки не надсилаємо повторно. Після наявного usage зменшуємо резерв за зафіксованим тарифом; без повного usage резерв лишається. Розрахована вартість — не банківська квитанція. Перед серією треба показати максимальний резерв; якщо залишку бракує на погоджений набір, зупиняємося без тихого скорочення контрольних прикладів.

## Транспорт і відмінності

Google — нативний stateless `models.generateContent`, який metadata API підтвердив для обох точних ID; він залишається підтримуваним, хоча Google рекомендує новий Interactions API. Використовуємо `systemInstruction`, `contents`, `generationConfig.responseJsonSchema`, JSON MIME і output 4096. Це свідомий вибір простого однокрокового endpoint без серверної історії, а не OpenAI compatibility. Ключ — лише заголовок `x-goog-api-key`, змінна `GOOGLE_API_KEY`.

Anthropic — нативний Messages, `ANTHROPIC_API_KEY`; погоджене вилучення непідтримуваних length/item constraints лише з wire schema, точні обмеження в системній інструкції й первісному локальному валідаторі. Google передає первісну schema, але сервер ігнорує string-length constraints — це теж явна відмінність constrained decoding. Спільний локальний валідатор залишається незмінним.

Хмарні reasoning/temperature залишаємо типовими для моделі, usage і фактичний model version записуємо. Відсутні reasoning tokens означають unknown. Google `candidatesTokenCount` і `thoughtsTokenCount` рахуються окремо; Anthropic `output_tokens` уже містить thinking, повторно його не додаємо. Порожня/незавершена відповідь — не успішний JSON.

Метадані ключем без генерації: Flash-Lite повернув version `3.5-flash-lite-07-2026`, input 1048576 / output 65536; Argon — version `3.0`, input 1048576 / output **32768**, що відрізняється від сторінки моделі (65536). Наш резерв 4096 нижчий за обидві межі; розбіжність зберігаємо, не підміняємо довідковою цифрою.

Джерела контрактів: [GenerateContent](https://ai.google.dev/api/generate-content), [Structured outputs](https://ai.google.dev/gemini-api/docs/structured-output), [Interactions overview](https://ai.google.dev/gemini-api/docs/interactions-overview). Доступність ID не доводить сумісність schema: це ще має підтвердити dev до freeze. Рішення зафіксовано до платного dev. Поточні результати 16 dev-викликів наведено в окремому [підсумку](2026-10-29-round-2-dev-results.md); holdout досі не викликався.

## Перевірка та межі

`round2/test_cloud.py` перевіряє нативний envelope, відокремлення reasoning, відмови/обрізання, відсутність витоку ключа, спільний залишок, повторне використання збереженої відповіді, заборону uncertain replay та відбір повних квартетів. Mock-тести не підтверджують реальну модельну якість. Зміни дослідницькі; продукт, його ролі та SPEC.MD не змінюються. Користувацькі інструкції UA/EN застосунку не потребують оновлення.
