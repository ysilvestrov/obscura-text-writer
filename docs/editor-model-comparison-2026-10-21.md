# Порівняння редакторів Venice — 21.10.2026

Мета: знайти профіль точкового редактора української прози, який виправляє мовні помилки, зберігає зміст і повертає застосовні правки. Це дослідницький прогін, без зміни архітектури або робочої прози.

Власник погодив до шести викликів на тій самій чернетці сцени фотосесії ню, із новим спільним лімітом $0,25, без автоматичних повторів після збою чи відмови. Використано ізольовану базу зі штатним обліком резервів. Робоча база читалася тільки для отримання зафіксованої чернетки. Усі п’ять моделей на момент перевірки мають `model_spec.uncensored=true`, доступні та підтримують JSON Schema в офіційному каталозі.

## Умови

Перші п’ять проб: той самий стандартний промпт редактора, та сама чернетка, температура 0,2, вихідний резерв 8192 токени, режим авторського перегляду. Reasoning вимкнений для reasoning-моделей; Gemma та Venice Uncensored позначені каталогом як моделі без reasoning. Контекстне вікно відповідає каталогу кожної моделі.

Шоста проба: Qwen 3.8 із тими самими параметрами, але `prompt_json` замість `json_schema`. Перевірялася окрема гіпотеза про вплив примусового формату; це не точне повторення першого виклику. Після отримання відповіді застосовувалися ті самі схема й guards.

«Недопустимих окремо» — кількість записів, що не проходять індивідуальні guards. Це не кількість літературно неправильних замін: технічно допустимий запис теж може псувати мову. Непридатні набори не ремонтувалися й не застосовувалися частково.

Повні відповіді трьох моделей не містили явної відмови через контент. Для двох проб без тексту та usage немає підстав ні встановлювати відмову, ні оцінювати мовну якість.

## Висновки та обмеження

- Температура 0,2 зробила Qwen обережнішим порівняно з попереднім тестом 0,7, але одна сцена й одна проба на профіль не доводять причинності або стабільності. Покриття мовних помилок незадовільне в обох форматах.
- Перехід із JSON Schema на JSON через промпт у шостій пробі не покращив кількість справжніх корисних виправлень. Гіпотеза про формат як основну причину слабкої редактури не підтвердилася на цьому прикладі.
- Gemma пропонує також ненормативні заміни; Venice Uncensored часто дублює вже наявні наступні слова. Більша кількість записів не означає кращу редактуру.
- Aion Mini та Qwen Plus не отримують оцінки мовної якості через незавершені технічні проби. Автоматичних повторів не було.
- Жоден перевірений профіль не рекомендовано для автоматичної редактури. Технічний успіх Qwen не є підтвердженням літературної якості.
- Це одна сцена, а не калібрування на репрезентативному наборі жанрів і рівнів складності.

Шість викликів завершено або зупинено; нових запитів немає. За usage підтверджено **$0,007480275**; у наносумах журналу після округлення — $0,007480276. Додатково збережено $0,039636875 невизначеної витрати Qwen Plus та $0,026828375 резерву Aion. Сумарна облікована експозиція — **$0,073945526**, менше погоджених $0,25. Невідомі витрати не оголошуються нульовими. Облік цієї серії зберігається в ізольованій тестовій базі, не в балансі робочого оповідання.
