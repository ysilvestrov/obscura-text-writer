# Venice Evaluator: перевірка 2026-10-21

Актуальний результат: робочу конфігурацію для попередніх звітів знайдено —
**qwen-3-8-27b / prompt_json / thinking off**. Деталі нової серії наприкінці.
Попередні результати Gemma нижче збережені як історія експерименту.

## Діагноз

Read-only перевірка останніх спроб локального твору виявила дві різні причини:
E2EE Gemma не підтримує JSON Schema; Abliterated Large V2 двічі повернула
незавершену відповідь `length`. Це не контентні відмови. Перший поточний
scene-запит: 17180 символів, приблизно 14594 вхідних токенів; разом із поточним
вихідним резервом 12000 — 26594, менше налаштованих 48000. Edit-pair:
20687 символів, оцінка 17661 + 12000 = 29661. Пам’ять не входить у ці запити.
Наведено лише агрегати; авторські тексти, exact requests і IDs не публікуються.

нижче кандидат **не рекомендований як робочий оцінювач із поточним промптом**.

## Дві синтетичні проби

Один невеликий вигаданий уривок із дорослою добровільною фотосесією,
навмисним мовним дефектом та прямою суперечністю плану; 5612 символів у запиті.
Це тест протоколу, не повне калібрування.

- Gemma: один completion, stop, коректний JSON, 1796 input / 488 output tokens.
  Знайшла суперечність із двома точними цитатами, але всі чотири обов’язкові
  критерії позначила not_checked через короткий текст, явний мовний дефект
  не відзначила. Статус incomplete, не якісний pass і не технічна помилка.
- Venice Uncensored 1.2: один completion, stop, 1931 input / 275 output tokens.
  Повернула refusal: недостатньо контексту для всіх критеріїв. Це явна відмова
  з невстановленою контентною причиною, не context overflow провайдера.
  Повтору цією моделлю для цього тестового матеріалу немає. Для production
  workflow такий outcome створив би story/model refusal block за R-04.

Консервативний сумарний резерв цих двох викликів $0.0139770625; фактичну
USD-вартість gateway у цих outcomes не отримав, тому її не вигадуємо. Резерв
усього поточного експерименту обмежено $0.03 з урахуванням попередніх
автоматизованих експериментів: envelope $0.35 + seven-scenes $0.21973386,
нижче stop $0.95 і погодженого бюджету $1. Це не ліміт витрат продукту або
ручних викликів користувача. Автоматичні повтори вимкнені.

## Погоджений тест першої сцени

Після окремого явного дозволу власника першу сцену з планом, брифом і каноном
надіслано до gemma-4-uncensored рівно одним completion-запитом. Поточний
story/model refusal block перевірено до запиту. Налаштування й дані твору не
змінювалися. Повторних запитів немає.

- Вхід: 17180 символів у повідомленнях; локальна оцінка 14594 токени.
- Usage провайдера: 6137 prompt / 583 completion / 6720 total tokens.
- finish_reason=stop; JSON відповідає схемі; failure=null; refusal=null.
- Українська, стиль, голос і дотримання плану: усі чотири not_checked, score=null.
- Findings: 0; це не доказ відсутності помилок, адже критерії не оцінено.
- Outcome: incomplete. Окремо лишається очікуваний profile_uncalibrated.

Модель заявила, що для мовного аудиту їй потрібні зовнішні інструменти,
для стилю — порівняльний baseline, для голосу — інші сцени, для вимоги обсягу —
інструмент підрахунку слів. Такі обмеження не роблять API-виклик помилковим і
не є контентною відмовою. Протокол правильно не перетворив not_checked на
успішну оцінку або низькі літературні бали. Story/model refusal block для цього
результату не потрібний: це неповне оцінювання, а не явний refusal.

Резерв одного виклику $0.0087669625; усіх трьох поточних проб —
**$0.022744025**, нижче погодженого $0.03. Фактична USD-вартість у gateway
outcome відсутня; резерв не оголошується фактичними витратами.

Висновок: контекст, API та JSON Schema працюють із цією конфігурацією,
але Gemma з чинним промптом не виконує обов’язкових оцінок навіть повної сцени.
Готовий JSON залишається відтворюваною експериментальною конфігурацією,
а не рекомендованим налаштуванням production Evaluator. Потрібна перевірка
іншого кандидата або окреме каліброване вдосконалення промпту; цей одноразовий
дозвіл не використовується для додаткових моделей чи повторів.

Артефакти поза Git: artifacts/venice-evaluator-2026-10-21/ — ledger,
raw responses, reports, точні requests, first-scene-summary.json і локальний
приватний кейс. У цьому документі немає авторської прози або exact requests.

## Пошук робочої конфігурації: нова погоджена серія

Власник явно дозволив ту саму приватну першу сцену на максимум трьох інших
uncensored-моделях Venice, новий резерв до $0.10 в загальному бюджеті $1,
без повторів після відмови. Використано дві моделі й п’ять completion-викликів:

| Модель / режим | Матеріал | Результат | Usage input/output |
|---|---|---|---:|
| GLM 4.7 Flash Heretic / json_schema | Перша сцена | refusal_unknown: послалася на зовнішні інструменти або контекст | 6394 / 605 |
| Qwen 3.8 27B / json_schema | Перша сцена | 4 not_checked, без явної відмови | 6343 / 542 |
| Qwen 3.8 27B / prompt_json | Та сама перша сцена | 4 assessed; 2 зауваження з перевіреними цитатами | 7035 / 1040 |
| Qwen 3.8 27B / prompt_json | Синтетичний clean | 4 assessed, усі бали 4, жодного finding | 2676 / 338 |
| Qwen 3.8 27B / prompt_json | Синтетичний adult_nudity_defect | 4 assessed; знайдено задане порушення узгодження підмета й присудка | 2616 / 485 |

Усі відповіді завершені stop. GLM після явної відмови записана в постійний
story/model block живого застосунку; повторів на ній не було. Qwen у native
режимі дала неповне оцінювання, а не refusal: це дозволило окреме контрольне
порівняння response_mode. Текст, рубрика, системний промпт, temperature=0.1 і
thinking off у парі Qwen однакові. У prompt_json наявний штатний builder додає
схему до промпту, а response_format не передає. Це окрема явна конфігурація,
не автоматичний fallback чи обхід збереженого блокування. Причина різниці
всередині провайдера не встановлена; один парний тест не доводить загальної
несправності JSON Schema або всіх інших моделей.

### Робочі параметри

- model: qwen-3-8-27b; provider: venice.
- response_mode: prompt_json; venice_disable_thinking: true.
- venice_include_system_prompt: false; temperature: 0.1; timeout_seconds: 180.
- context_tokens: 262144; max_output_tokens: 3000; max_input_chars: 100000.
- policy: report; profile лишається candidate, calibrated=false.

Новий UI JSON: config/evaluator.venice.qwen-3-8.ui.example.json. Загальний CLI
приклад config/evaluator.venice.example.json також використовує цю конфігурацію.
Qwen у каталозі має uncensored=true, supportsResponseSchema=true, context262144,
maxCompletion65536; опцію thinking off підтверджено usage reasoning_tokens=0.

Перевірену конфігурацію збережено через штатний локальний API в тому самому
оповіданні. До запису зроблено приватну резервну копію старих налаштувань і
перевірено, що вони не змінилися незалежно. Повторний GET підтвердив точний
config, context262144, policy=report, calibrated=false й відсутність block для
Qwen. Попередній profile/пороги й policy збережені; рольові моделі, проза та
історичні звіти не переписувалися. Перезапуск сервера для зміни не потрібен.
Нового inference під час встановлення налаштувань не було.

Offline-перевірка збережених outcomes підтвердила всі обов’язкові assessed для
трьох успішних кейсів, відсутність хибних findings у clean, потрібну цитату й
критерій ukrainian у adult_nudity_defect, нуль unconfirmed findings. Першій
сцені присвоєно бали 3/3/4/4 (українська/стиль/голос/план). Перевірка цитати
підтверджує наявність фрагмента, а не безпомилковість літературного судження.

У трьох успішних кейсах outcome=incomplete **лише** через profile_uncalibrated;
критерії оцінено повністю. Це придатно для попередніх звітів у report, але не
дає права автоматичного pause_on_failure. Повний контрольний набір із трьома
повторами, revision/story-режими та ширші дорослі теми цією серією не перевірені.

Сумарний консервативний резерв нової серії **$0.09249893**, менше погоджених
$0.10. Разом із prior envelope0.35, seven-scenes0.21973386 та попередньою серією
0.022744025 це $0.684976815, менше stop0.95 і бюджету1. USD billing у gateway
usage відсутній; резерв не оголошується фактично списаною сумою. Нових
автоматичних викликів після цих п’яти не запускаємо.
