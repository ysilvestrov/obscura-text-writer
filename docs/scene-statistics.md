# Статистика сцени

Під редактором показано слова й символи видимого буфера. Пробіли та переноси входять у символи; апостроф або дефіс усередині слова не розбиває його. Рядок позначає незбережений буфер, збереження, історичну версію або JSON. У табличній пам’яті дивіться counts записів, а не слова прихованого JSON.

Розгорніть **«Статистика сцени й контексту»**. Збережені план, завдання, чернетка й проза пораховані окремо; альтернативи/історія не подвоюють обсяг. Проза зіставлена з орієнтиром слів сцени. Ручний незбережений текст у серверні деталі не входить.

Пам’ять показує префікс попередніх сцен та журнал після поточної, чинні записи й усі події, внесок сцени, додавання/оновлення/закриття. Приховані прапорцем «передавати далі» записи з журналу не зникають і в його counts враховані. Контекст нижче вже враховує проєкцію/прапорці/учасників. Застарілі журнали позначені; відсутні або некоректні дані не називаються нулями. Майбутні джерела не враховуються.

Оберіть етап: **«Створити завдання»**, **«Написати»**, **«Редагувати»** чи **«Оновити пам’ять»**. Показано контекст саме збережених даних. Для редактора це початкова робоча копія — поточна проза або, за її відсутності, чернетка. Наступні проходи матимуть уже змінений текст. Відсутні передумови показуються причиною. Якщо вхід завеликий, розбивка лишається доступною.

Байти JSON по джерелах складаються у повний запит. Колонка токенів — пропорційний розподіл чинної консервативної/емпіричної оцінки, **не токенізатор моделі**. Службовий рядок містить обгортку й резерв оцінки; резерв відповіді вказаний окремо. Останній фактичний usage (включно з reasoning, якщо провайдер його надав) показаний окремо з моделлю/датою й може стосуватися іншого профілю. Невідоме usage не дорівнює нулю.

Панель оновлюється при зміні сцени/серверних матеріалів, зміні етапу або кнопкою **«Оновити статистику»**. Підрахунки локальні; платних викликів, запуску моделі або зміни тексту/пам’яті немає.
