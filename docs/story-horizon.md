# Горизонт майбутнього сюжету

У налаштуваннях кожної ролі є блок **«Горизонт майбутнього сюжету»**:

- **Поточна та всі наступні сцени** — типовий попередній режим.
- **Поточна та N наступних сцен** — поточний план і найближчі N активних планів. Поточна сцена не входить у N. Значення від 0 до 1000; 0 залишає лише поточну.
- **Лише поточна сцена** — без окремих планів наступних сцен.

Наприклад, для сцени 3 й N=2 модель отримає плани 3, 4, 5. Якщо наступних сцен менше, беруться всі наявні. Сцени в кошику не рахуються. Плани не скорочуються автоматично заради token budget: переповнення лишається явною помилкою.

Планувальник і письменник можуть мати різні горизонти. У планувальника налаштування стосується створення завдання письменнику; підготовка структури з імпортованого матеріалу, як раніше, читає повний план. Для повної літературної редактури `prose` горизонт доступний; режими `patches`/`diff` читають лише чернетку, тому керування вимкнене. Пам’ять не отримує майбутніх планів.

У формі **«Профіль письма»** можна додати **«Авторський орієнтир фіналу»** — спільний задум розв’язки до 12000 символів. Це необов’язковий авторський текст, не автоматичний переказ останнього плану. Для режиму лише поточної сцени його відсутність дає попередження, але не блокує запуск. Орієнтир передається окремо як задум, із вказівкою не завершувати весь твір у неостанній сцені.

Горизонт обмежує лише окремо підставлені плани. Канон, преамбула, стиль, власний промпт, бриф чи чернетка можуть уже містити відомості про фінал. Програма не вирізає ці тексти приховано. Якщо широкий бриф залежить від далекого плану, зміна цього плану й надалі може зробити бриф та залежну чернетку застарілими. Щоб дослідити вузький горизонт послідовно, налаштуйте його також для планувальника та створіть новий бриф.

Зміна плану поза горизонтом сама по собі не впливає на прямі залежності поточного результату. Зміни включених планів та порядку вікна відстежуються. Загальна кількість сцен теж залишається залежністю: вона показана моделі в заголовку `сцена n/total`.

Збережіть роль після зміни горизонту, а профіль письма — після зміни орієнтира. Активний виклик зберігає свої зафіксовані параметри; наступний етап читає нові. Комплекти R-11 переносять горизонт ролі, але не авторський текст фіналу. Збережені оповідання без нових налаштувань залишаються у режимі всіх планів.

Offline-тести доводять вибір джерел, залежності та збереження налаштувань. Вони не доводять, що конкретна модель краще пише з меншим горизонтом; для цього потрібен окремий літературний експеримент.
