# Мотиви архітектурних рішень

ADR пояснюють **чому** обрано рішення. Чинний контракт визначає [SPEC.MD](../../SPEC.MD), а виконання перевірок — [STATUS](../STATUS.md).

- [ADR-001: локальний запуск і межа приватності](001-local-runtime.md).
- [ADR-002: доказова пам’ять і хронологічний префікс](002-evidence-memory.md).
- [ADR-003: явні провайдери без fallback](003-no-fallback.md).
- [ADR-004: редакторські копії та один спільний diff](004-editor-review.md).

Дата нижче означає дату документування мотивів уже реалізованого рішення, а не дату початкового його ухвалення. ADR не дозволяє змінювати поведінку без актуалізації SPEC.
