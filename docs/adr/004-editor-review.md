# ADR-004 — Робочі копії та один спільний diff

Статус: прийняте й реалізоване рішення; мотиви записано 21.10.2026.

Кілька редакторських проходів знаходять додаткові проблеми, але можуть також змінити зміст. Цикл працює на незмінних приватних draft-копіях; фінальний програмний diff об’єднує зміни для одного авторського рішення на сцену. Допоміжна модельна класифікація необов’язкова й не визначає позиції правок.

Наслідок: до прийняття поточна проза не замінюється, число викликів обмежене, нуль змін не пропонується як новий результат. Ліміт не доводить мовної чистоти. У комплексному workflow явне продовження після прийняття запускає пам’ять. Контракт: [EDIT-LOOP](../../SPEC.MD#edit-loop), [EDIT-WORKFLOW](../../SPEC.MD#edit-workflow), [EDIT-NO-CHANGES](../../SPEC.MD#edit-no-changes).
