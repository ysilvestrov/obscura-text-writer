# ADR-002 — Доказова пам’ять і префікс

Статус: прийняте й реалізоване рішення; мотиви записано 21.10.2026.

Модельний переказ може втрачати факти й містити події з майбутнього. Тому повний журнал зберігає джерела та докази, а в письменницький запит надходить окрема компактна проєкція. Письменник сцени n використовує тільки префікс до n−1; update/retire станів лишають історію.

Наслідок: перевірка точних доказів не доводить семантичної правдивості твердження, а повна хронологія все одно росте. Overflow явний, без прихованого summary або відкидання.
