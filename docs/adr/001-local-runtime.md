# ADR-001 — Локальний запуск

Статус: прийняте й реалізоване рішення; мотиви записано 21.10.2026.

Автор працює з приватними текстами, локальними моделями й хмарними API за явним вибором. Сервер, UI і сховище працюють локально під одним AppInstanceLock на каталог даних. Це спрощує відновлення та контроль файлів і не потребує багатокористувацької автентифікації.

Наслідок: сервер не призначено для публічного розгортання; файли відкриті локальному користувачеві. Хмарний провайдер усе одно отримує контекст явно запущеного виклику. Gitignore не обмежує читання AI-інструментами. Контракт: [RUNTIME-001](../../SPEC.MD#runtime-001), [PIPE-002](../../SPEC.MD#pipe-002), [SECURITY-001](../../SPEC.MD#security-001).
