# ADR-003 — Явний провайдер і відсутність fallback

Статус: прийняте й реалізоване рішення; мотиви записано 21.10.2026.

Прихована заміна моделі змінює витрати, конфіденційність і властивості результату. Тому виклик використовує явно налаштовану модель, а помилка чи відмова не спричиняє повтор або fallback. Для Venice uncensored=true — необхідна перевірка каталогу, але не доказ поведінки.

Оцінювач після контентної або непоясненої явної відмови блокується для цього твору. Технічна помилка не створює такого блоку й не стає літературним штрафом. Новий профіль потребує власного калібрування. Контракт: [MODEL-002](../../SPEC.MD#model-002), [MODEL-003](../../SPEC.MD#model-003), [EVAL-006](../../SPEC.MD#eval-006).
