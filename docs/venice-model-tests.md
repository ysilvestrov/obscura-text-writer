# Venice.AI: проба uncensored-моделей

19 жовтня 2026 року. Користувач явно підтвердив передавання авторських бітів `scena-photos-nu.txt` до Venice.AI та чотири генерації сумарно до $0,20. До цього підтвердження виконано лише GET каталогу; початкове відхилення автоматичної перевірки дозволів не обходилося.

## Відбір і протокол

Ключ `VENICE_API_KEY` із локального `.env`, endpoint `https://api.venice.ai/api/v1`. GET `/models?type=text` повернув HTTP 200 і 137 текстових моделей. Клієнтський фільтр **`model_spec.uncensored is True` та `offline != true`** залишив 12 моделей. Пошук лише за назвою чи описом не використаний для остаточного відбору. Каталог і точний відфільтрований список збережені у `artifacts/venice-pilot`.

Відбір відповідає атрибуту провайдера; сам прапорець ще не доводить відсутності відмов на будь-якому матеріалі. Джерела API: [перелік моделей](https://docs.venice.ai/api-reference/endpoint/models/list), [моделі й ціни](https://docs.venice.ai/models/text), [chat completions](https://docs.venice.ai/api-reference/endpoint/chat/completions).

Усі чотири запити отримали однаковий чинний writer prompt, дослівні авторські біти, орієнтир 400 слів і окремий контекст: повнолітні учасниці, професійна фотосесія ню за згодою клієнтки. Оригінальний файл не змінений; копію та SHA-256 збережено. У запитах не просили додавати еротичних дій понад авторський план.

Параметри: OpenAI Python SDK, `max_retries=0`, `max_tokens=4096`, температура 0,5. Доданий Venice system prompt і вебпошук вимкнені для порівнюваності. Для Qwen надіслано підтримуваний параметр Venice disable_thinking=true; Aion використала штатний режим reasoning. Це записано в exact requests. Fallback/повторів/переписування запиту після відмови не було. Усі моделі завершили з `finish_reason=stop`, без refusal. Редакторський чи структурований JSON-контракт у цій серії не тестувався.

## Автоматична оцінка

Чотири окремі candidate-звіти через раніше погоджений Codex CLI gpt-6-luna, з тим самим планом і вимогами. Це використання Codex обліковується окремо від вартості Venice. Оцінювач раніше не пройшов калібрування, тому оцінки не є рейтингом доведеної точності чи літературним прийманням.

|---|---:|---:|---:|---:|---:|
| Venice Uncensored 1.2 | 3 | 2 | 2 | 2 | 4 / 0 |
| Role Play Uncensored | 1 | 1 | 1 | 2 | 4 / 1 |
| Qwen 3.6 Plus | 3 | 3 | 3 | 4 | 3 / 0 |
| Aion 3.5 | 3 | 3 | 2 | 3 | 3 / 3 |

«Підтверджений finding» тут означає проходження механічної перевірки цитат, а не доведену правильність літературного судження. Усі чотири звіти мають статус incomplete через некалібрований профіль; для деяких також є недостатнє покриття/непідтверджені докази. Непідтверджені findings не зараховувалися як доведені дефекти.

## Рішення

**Qwen 3.6 Plus Uncensored — перший кандидат для наступного письменницького тесту**, Aion 3.5 — другий для зіставлення точності плану. Дві Venice 24B-моделі за цією українською пробою не обираємо для основного письменника. Це висновок за однією сценою, без твердження про універсальну якість чи відсутність цензури в інших сценаріях.

Наступна змістовна перевірка: стабільність Qwen на кількох різних сценах і сумісність її прози з нашим точковим редактором та пам’яттю. Перший етап був прямим API-пілотом. Нижче — результат наступної погодженої інтеграції.

Відтворення: `artifacts/venice-pilot/run.py`; exact requests, raw responses, тексти, каталог, usage/cost і звіти — поруч, поза Git. Короткі зведення — `summary.json`, `cost-summary.json`, `evaluations.json`.


## Інтеграція провайдера та повний цикл

Venice додано окремим провайдером усіх чотирьох ролей. Офіційний endpoint — `https://api.venice.ai/api/v1`, серверний ключ — `VENICE_API_KEY`. Каталог запитується з `type=text`; приймаються лише буквальне `uncensored=true` та online-моделі. Перед кожною генерацією перевірка повторюється, включно з підтримкою JSON Schema. При відсутності моделі чи потрібної можливості запит завершується помилкою без підміни моделі. Скасування під час завантаження каталогу не запускає completion.

В інтерфейсі можна окремо ввімкнути системний промпт Venice (типово вимкнений) і вимкнути thinking (типово не вимикається). Вебпошук, scraping і X search вимкнені. Зберігаються точні параметри, частковий текст, usage і повідомлена Venice вартість `cost.usd`/`cost.diem`; ключі не серіалізуються.

У межах нового загального бюджету до $1 виконано чотири запити `qwen-3-6-plus`: бриф, проза, точкові правки, пам’ять за фрагментами. Всі завершені з `stop` і пройшли перевірки застосунку. Системний промпт Venice вимкнений, thinking вимкнений, JSON Schema для структурованих етапів, температура письменника 0,5, інших ролей 0,2. Отримано 361 слово за простим поділом пробілами; ціль — приблизно 400.

Попередній резерв цього прогону — $0,108311125, ліміт експериментального transport — $0,50, максимум чотири completion-запити. Перші чотири Venice-проби коштували $0,018690725; разом обидві Venice-серії — $0,030263055. Попередні OpenRouter витрати обліковуються окремо; жодного нового OpenRouter запиту в цьому прогоні немає. Це бюджетний захист експериментального скрипту, а не глобальний ліміт витрат у продукті.

Редактор запропонував лише `фотографка` → `фотограф`. Це не підтверджує поліпшення мови: нормативний фемінітив не потребує такої заміни. Пам’ять має дослівні цитати та правильний ID версії, але механічна перевірка цитат не доводить правильності висновків. Наприклад, твердження про згоду Лани на право зупинити процес підкріплено реплікою Лєри про це право, а не окремою відповіддю клієнтки. Розповідь також вийшла в теперішньому часі при профілі минулого часу. Отже, технічний цикл пройдено; літературне приймання й семантична надійність пам’яті залишаються відкритими.

Після окремого явного дозволу користувача виконано одну автоматичну оцінку через Codex CLI gpt-6-luna: план, вимоги, чернетка та редактура передані одним revision-кейсом. Повторних Venice/OpenRouter генерацій немає. Codex usage обліковується окремо; USD-вартість цей CLI-звіт не повідомляє.

Три minor-зауваження: спосіб виправлення освітлення відрізняється від плану; абстрактні метафори; шаблонні/незвичні сполучення. Всі три мають цитати, що дослівно є в документах; непідтверджених цитат немає. Перевірка цитат підтверджує їх наявність, а не правильність судження. Зауваження про «магію» радше стилістичне, ніж доказ мовної помилки.

Оцінювач не відзначив явне порушення заданого минулого часу й не розібрав єдину заміну нормативного «фотографка» на «фотограф». Тому 4/4 за збереження редактури не підтверджує корисність редактора. Статус — **incomplete**, причина `profile_uncalibrated`; міжсценову послідовність не перевірено, пам’ять не була входом оцінювача. Прохід якості не зараховано. Наступний крок для оцінювача — контрольні приклади порушення часу, зайвої заміни фемінітива та помилкових висновків із правильної цитати перед новим калібруванням.
