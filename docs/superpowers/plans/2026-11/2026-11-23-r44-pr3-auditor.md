# R-44 PR 3 — роль «Ревізор» і перевірка сцени: план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** п'ята роль «Ревізор» (`auditor`) з трьома перевірками зв'язків сцени (З1 `audit_brief`, З2 `audit_prose`, З3 `audit_memory`), що пишуть `LinkVerdict(source='auditor')`, і запуск черги `audit` для однієї сцени з кнопкою «Перевірити сцену» та панеллю розбіжностей.

**Architecture:** роль додається в реєстр `roles.py`; без власного рядка налаштувань Ревізор бере провайдера редактора й ліміти планувальника. Контекст перевірки збирається окремо від `build_context` (як `timeline_summary`) і не відмовляє через позначку «застаріле». Виклик іде через `execute_stage` (політика, бюджет, спроба); результат — не версія, а висновок, записаний однією транзакцією з CAS за відбитком зв'язку й маркером інвалідації. Запуск `audit` на кожному кроці бере перший невалідний зв'язок сцени й зупиняється в `needs_review` на розбіжності.

**Tech Stack:** Python 3.12, Pydantic v2, FastAPI, SQLite (`app_settings`), vanilla JS (ES modules), pytest, node-скрипти JS-тестів, Playwright.

**Spec:** `docs/superpowers/specs/2026-11/2026-11-23-book-validation-design.md` (розділи 5, 6, 7, 8, 9, 12, 13, 15). Чинна архітектура — `SPEC.MD` (VALID-LINKS, VALID-MEMORY, VALID-CARDS, MODEL-001…004).

## Global Constraints
