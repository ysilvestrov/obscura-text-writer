# MCP, пакет 6, PR 1: режим твору — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** твір має режим «пише чат» / «пише Obscura»; автор вибирає його у формі нового твору й перемикає в налаштуваннях; сервер відхиляє записи текстів від моста в режимі «пише Obscura» і зміну режиму мостом.

**Architecture:** поле `Story.writing_mode` (JSON-запис, без міграції); `PUT /api/stories/{id}/writing-mode` за зразком мови; міст позначає запити заголовком `X-Obscura-Client: mcp`, сервер читає його функцією `from_bridge(request)` і перевіряє режим у маршрутах запису від чату. Інтерфейс — вибір у `library.html` і перемикач у розділі письма налаштувань за зразком `story-language.js`.

**Tech Stack:** Python 3.12, FastAPI, httpx, `mcp==2.3.0`, Jinja, ES modules, pytest.

**Spec:** `docs/superpowers/specs/2026-11/2026-11-12-mcp-p6-obscura-writes-design.md` (затверджено 2026-11-12; у формі типово «пише Obscura»; перегляд перед запуском обов'язковий — PR 2).

## Global Constraints

- `writing_mode: Literal['chat','obscura']`; типове значення моделі — `chat` (чинні твори, `create_story` моста); форма бібліотеки типово надсилає `obscura`.
- Заголовок: `X-Obscura-Client: mcp` (точне значення); без нього обмежень немає.
- Тексти відмов: режим `obscura` для записів від моста → 409 «Твір у режимі «пише Obscura»: чат не записує тексти — запустіть етап в Obscura»; зміна режиму мостом → 403 «Режим твору змінює лише автор в Obscura».
- Зміна режиму: `expected_revision`, ревізія +1; той самий режим — без змін.
- i18n uk/en, лише `textContent`; нейтральні тексти в тестах.

## Review Focus

1. Запис чернетки з інтерфейсу (без заголовка) у творі «пише Obscura» проходить (тест у задачі 1).
2. Чинний твір без поля читається як `chat` (тест у задачі 1).
3. Зміна режиму зі старою ревізією → 409, без зміни (тест у задачі 1).
4. Відкрита сторінка налаштувань помічає зміну режиму ззовні (режим у підписі вмісту; node-тест у задачі 2).
5. `create_story` моста без `writing_mode` створює «пише чат» (тест у задачі 3).
