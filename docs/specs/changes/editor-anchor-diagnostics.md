# Діагностика дослівних якорів редактора — 22.10.2026

Дві останні невдалі patches-спроби моделі abliteration-abliterated-model-large-v2 завершилися stop та валідним JSON. Локальне порівняння з незмінним джерелом: правка14/15 у f000035 та3/5 у f000015 містять original з помилкою одного символу; точного збігу немає навіть в усій сцені. Це порушення протоколу копіювання, не встановлена контентна відмова. Авторський текст і сирі відповіді в репозиторій не копіюються, зовнішнім сервісам не надсилаються.

Виправлення: структурований CopyEditAnchorError з індексом/кількістю правок, безпечним ID фрагмента й окремою причиною missing fragment/missing original/ambiguous original. Публічний editor_failure лишає category=guard для сумісності; додає пояснення відхилення всього набору та ручну альтернативу diff. Валідація залишається строгою, без нечіткого зіставлення, часткового застосування чи повторного модельного виклику. SQL/збережені спроби/профіль твору не змінюються.

Сценарій і контракт: SPEC EDIT-DIAGNOSTICS-S02. Перевірка: tests/generation/test_editor_output.py, RED→GREEN для безпечного діагностування індексу/причини; регресія guard/loop/review. Локальні дані прочитані через SQLite mode=ro; старі помилки не переписуються. Практична рекомендація для цієї моделі — обрати повний текст із diff: там original будує скрипт, а не копіює модель. Це не гарантія літературної якості та не зміна налаштувань без автора.
