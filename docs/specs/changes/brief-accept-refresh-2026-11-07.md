# Оновлення доступності прийняття завдання

Дата: 07.11.2026. Після генерації пропозиція завдання має дозволяти прийняття одразу після завершення активного запуску, без перемикання вкладок. Повторне відображення має реагувати на оновлення списку запусків, зберігаючи блокування для активних запусків, незбережених змін, неактуальної чи неповної пропозиції. Альтернативу — прибрати перевірку активного запуску — відхилено, бо це послаблює захист під час генерації. Контракти API і дані не змінюються.
