# Фільтр таблиці пам’яті за сценою

Дата: 08.11.2026. Мета — швидко переглядати записи пам’яті за сценою-джерелом.

Таблиця має комбінований список «Усі сцени» та сцен твору; початково вибрана поточна сцена. Вибір фільтрує наявні рядки за їхнім `source_scene`, разом із пошуком і категорією. «Усі» включає записи з невизначеним джерелом. При переході до іншої поточної сцени фільтр повертається до неї; при оновленні тієї самої сцени вибір зберігається. Приховані фільтром незбережені прапорці зберігаються та входять до наступного Save. Порожній результат показує чинне повідомлення. Перемикання фільтра не змінює журнал, сцену або серверні контракти. Український і англійський інтерфейс та інструкції оновлюються разом.

Перевірки: тест DOM для поточної/іншої/всіх сцен, поєднання фільтрів, збереження прихованого прапорця і зміни поточної сцени; `check_docs.py`, повний `verify.py`. Нових міграцій чи конфігурації немає.
