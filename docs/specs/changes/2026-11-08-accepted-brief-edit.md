# Редагування прийнятого завдання

Дата: 08.11.2026. Пряме рішення власника змінює R20-BRIEF-REVIEW-S04: ручне збереження правки показаного прийнятого завдання зберігає попереднє прийняття. Клієнт передає ID версії, з якої редагується буфер; сервер порівнює його з поточним selected brief head і scene revision. Якщо вони збігаються, авторська версія стає head навіть з proposed_changes. Якщо редагується неприйнята пропозиція, вона й надалі чекає окремого прийняття. Відсутній source ID старих клієнтів зберігає попередню консервативну поведінку. CAS, перевірка залежностей і захист dirty-буфера залишаються. Нова SQL-міграція не потрібна. Перевірки: прямий Save і Save перед генерацією, нова неприйнята пропозиція, застарілий source/revision, сумісність старого клієнта та конфлікт без заміни head.
