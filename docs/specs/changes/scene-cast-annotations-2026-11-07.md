# Пояснення біля учасників сцени

Дата: 07.11.2026. Пояснення у круглих дужках у рядку учасників залишаються в авторському плані та контексті планувальника, але не входять до імені для зіставлення з картками. Кома або крапка з комою всередині збалансованих дужок не розділяє учасників. Точний ID або повна назва картки має пріоритет; неоднозначне чи невідоме ім'я, як і раніше, блокує генерацію. Тексти, сховище та формати не мігруються; збереження зміненого плану оновлює склад, а незмінний Save лишається no-op і не скасовує ручний вибір.
