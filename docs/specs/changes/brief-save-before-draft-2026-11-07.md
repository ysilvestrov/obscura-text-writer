# Збереження завдання перед чернеткою

Дата: 07.11.2026. Якщо основна дія зберігає змінене завдання як нову пропозицію з proposed_changes, повторна перевірка після збереження SHALL зупиняти запуск чернетки до явного прийняття цієї версії. Попередній head не змінюється; API і модель даних не змінюються. Виправляється запуск із попереднім head без рішення щодо нової пропозиції. Альтернативу автоматично приймати версію відхилено: вона усувала б явне рішення автора.
