# Чистий авторський експорт

25.10.2026. Пряме рішення автора: після явного дозволу публікувати неперевірені сцени службові попередження не додаються до тексту або внутрішніх метаданих MD/TXT/FB2/EPUB/PDF. Вони залишаються в окремому manifest. Початкове підтвердження, integrity guards та обов’язкові метадані збережені; порожні книги лишаються структурно валідними без службових заглушок. Старі експорти незмінні, новий exporter protocol=4. SQL та manifest schema2 без міграцій.
