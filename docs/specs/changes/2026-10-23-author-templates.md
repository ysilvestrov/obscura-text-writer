# Завантажувані шаблони плану й персонажів

Прямий запит власника 23.10.2026. Реалізація: два UTF-8 Markdown-ресурси в `storygen.web/static/templates`, включені до package-data. У «Додати матеріали» над імпортом — два same-origin посилання з download та зрозумілими іменами файлів. Новий API, модельний виклик або міграція не потрібні.

План: заголовки «Сцена N: Назва», місце, склад, попередні події, подія/дії, усвідомлення й емоція; додано Початок/Кінець у форматі «день N, HH:MM». Приклад другої сцени перетинає північ: день1 23:40 → день2 00:20. Порядок читання не змінюється на фізичну хронологію. Часові рядки — звичайні авторські біти, а не нові машинні поля; автоматичного обчислення/перевірки тривалості не додається.

Персонажі: заголовки імен другого рівня відповідають учасникам плану; початкові риси/голос/мотивація/знання. Пояснено, що текстова дата не створює availability; після імпорту картки unclassified і потребують наявних UI-позначок доступності. Майбутні відомості рекомендовано додавати окремо через картки.

Перевірка: download bytes == package resources; реальний імпорт обох шаблонів створює рівно дві сцени й дві картки, заповнює склад, зберігає час дослівно. Окремо — wheel resources та браузерний desktop/mobile перегляд посилань. Контракт: DATA-001-S02.
