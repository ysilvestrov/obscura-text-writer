25.10.2026. Виправлення дефекту за повідомленням власника: довгий текст збільшує висоту ProseMirror, toolbar зникає за межами сторінки. У CSS встановлено лише min-height, без обмеження висоти/overflow.

Панель B/I/comments/undo/redo лишається поза її scroll area. Прокрутка тексту не рухає toolbar або документ сторінки. Формат збереження, anchors, API й схема бази не змінюються; restart сервера не потрібен, достатньо reload після збереження локального вводу.
