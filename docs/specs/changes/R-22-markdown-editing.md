# R-22 — Форматоване редагування з Markdown-джерелом

Дата: 24.10.2026. Статус: спільний UX-дизайн погоджено власником 24.10.2026 («Ок»). Технічний план погоджено; R-22a/b (ядро/source map/збірка, visual adapter і version metadata) реалізовано. R-22c (Markdown preservation, evidence guards і формати книг) реалізовано; R-22 завершено. Коментарі/rewrite — наступні пакети R-23.

## Мета і межі

Візуальний редактор авторського тексту з панеллю жирного/курсиву, без режиму сирого Markdown. Чинні тексти, no-op Save, undo/redo, Unicode/переноси, історія та доступність зберігаються. Форматування має відтворюватися в FB2/EPUB/PDF; MD лишається джерелом. JSON пам’яті й завдання не стають rich text. AI-assisted спочатку працює лише з чернеткою.

Спільний погоджуваний UX та рішення власника: [дизайн R-22/R-23](R-22-R-23-authoring-design.md). Сама система коментарів/переписування належить R-23; R-22 надає для неї межу тексту, виділення й позначок.

## Запропоновані вимоги

- Editor API SHALL читати/писати авторитетний Markdown та надавати точне виділення й відстеження правок, не змушуючи workflow працювати з DOM або textarea.value.
- Відкриття/перемикання UA/EN/вкладки без правки SHALL не нормалізувати source й не створювати зайвих версій. Серіалізація зміненого документа SHALL не втрачати вміст/форматування поза редагованою ділянкою.
- Мітки коментарів SHALL відображатися фоном, залишаючись окремими від Markdown/експорту. Зміни до/після фрагмента SHALL коректно переміщати прив’язку; перетин зі зміною SHALL повідомляти R-23 про потребу перевірки.
- Безпечне вставлення/рендер SHALL не виконувати авторський HTML. Непідтриманий Markdown SHALL не видалятися мовчки; точна політика й редакторська бібліотека визначаються технічним планом.
- Експортні рендерери SHALL узгоджено відтворювати дозволений Markdown; джерела, цитати й зміни координат SHALL перевірятися проти збереженої версії, а не візуального HTML.

## Перевірки й сумісність

Plain text до/після відкриття, жирний/курсив/комбінація/Unicode, Save без змін, undo/redo, clipboard/HTML, відкриття старих версій, джерела пам’яті й редакторські anchors, передавання виділення R-23, FB2/EPUB/PDF/TXT/MD, UA/EN, desktop/mobile/keyboard. Модельні промпти й бюджети не змінюються цим пакетом самі по собі. Root SPEC/traceability оновлюються разом із реалізацією, а не наперед.
