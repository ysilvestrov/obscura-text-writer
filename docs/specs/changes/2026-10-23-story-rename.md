# Перейменування оповідання

Статус: реалізація прямого запиту власника 23.10.2026.

Біля назви твору — SVG-кнопка олівця з доступною назвою. Вона замінює заголовок на поле та «ОК»; Enter зберігає, Escape скасовує. Під час збереження поле й кнопка заблоковані. Помилка лишає введення для виправлення; повторне відкриття після конфлікту використовує прочитані актуальні метадані, без перезавантаження тексту сцени. Незбережена назва захищена beforeunload.

PATCH /api/stories/{id}: title та expected_revision, повертає Story. Authoring/Repository транзакційно перевіряють активність твору та CAS ревізії, обрізають лише зовнішні пробіли, приймають 1–300 символів. Зміна підвищує тільки story.revision; однакова назва — no-op після CAS. Тексти/голови/актуальність сцен, config_revision і явно задана publication.title незмінні. Порожня publication.title як і раніше використовує story.title. Схема БД незмінна; старі клієнти сумісні.

Порядок реалізації: RED API/Node → storage/service/route → inline UI з чинними токенами → OpenSpec/traceability → цільові регресії та синтетичний desktop/mobile → перезапуск після дозволу автора й перевірки active runs. Автор підтвердив відсутність незбережених правок і генерації.
