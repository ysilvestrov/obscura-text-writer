# Відновлення місця роботи у творі

25.10.2026. Виправлення за запитом власника: reload повертає план першої сцени.

Зберігати в localStorage окремо для кожного story ID тільки scene ID та одну із шести поточних workflow вкладок. Не зберігати тексти/коментарі чи історичний version ID. При відкритті чинний scene/material URL має пріоритет над browser preference; наступні переходи синхронізують URL через replaceState, щоб reload не повертав до застарілих параметрів. Відновлення виконується один раз після завантаження active scenes і реєстрації material loader, з guard проти нового вводу/переходу. Видалений/чужий scene ID дає план першої доступної сцени. Немає scenes — немає автоматичного вибору. Некоректний JSON/недоступний storage не блокують редактор; URL продовжує працювати. Відновлення не запускає моделей і не записує рукопис.

Перевірити desktop/mobile: друга сцена+вкладка після reload, розділення творів, явний URL, новий вибір після URL, повернення за звичайним посиланням, видалений scene й відмову storage. API/SQL/запуск сервера не змінюються.
