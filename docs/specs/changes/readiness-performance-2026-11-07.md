# Швидка перевірка готовності робочого простору

Дата: 07.11.2026. Мета — зменшити очікування перевірки передумов без послаблення перевірок, згоди на пам’ять, бюджетів і скасування.

## Рішення

Readiness API приймає необов’язковий перелік потрібних операцій; без нього повертає повний сумісний набір. Основна дія запитує лише власну операцію. Фонове оновлення згортає одночасні події і запускає наступну перевірку лише після завершення попередньої; відкриті додаткові команди отримують повний набір, інакше — тільки операцію активного режиму. Запуск повторно перевіряє вибрану дію, сервер enqueue незалежно виконує остаточний preflight. Старі відповіді не повинні переозначати новий стан сцени чи режиму; скасування та memory consent зберігаються.

Альтернатива глобального кешу відкинута через складну інвалідацію залежностей і ризик застарілих дозволів. Зміна не вводить model calls, схему БД або додаткові зовнішні сервіси.
