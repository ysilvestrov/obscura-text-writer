# Бюджет модельних викликів

## У вебзастосунку

Відкрийте налаштування оповідання → «Бюджет викликів». Задайте загальний
ліміт USD і натисніть «Зберегти ліміти». Без цього Venice/OpenRouter не
отримають completion-запиту. Старий усний дозвіл на тестування не переноситься
в налаштування автоматично. Local і підписковий Codex не потребують USD-ліміту.

Необов’язковий типовий ліміт запуску застосовується з першого резерву нового
запуску. На робочій сторінці його можна перевизначити для наступного запуску.
Зміна типового значення не переписує вже зафіксований ліміт активного запуску.
Ліміт накопичувальний: щоб дозволити додаткові витрати, збільшіть загальну суму.
Перезапуск, кошик і нова спроба не обнуляють облік.

Для тарифу виберіть провайдера й точний Model ID та натисніть «Оновити з
каталогу». Це GET без авторського тексту. Офіційний тариф чинний 24 години.
Перед викликом застарілий офіційний тариф оновлюється; за відсутності придатних
даних виклик блокується. Можна явно зберегти ручні ставки: вхід/вихід у USD
за мільйон токенів, USD за запит, джерело й майбутню дату завершення дії.
Ручний тариф спільний для цієї моделі/провайдера/endpoint у каталозі даних;
його прострочення вимагає нового підтвердження або оновлення з каталогу.

## Що означають суми

- «Підтверджено»: API повідомив вартість або автор вручну звірив її з джерелом.
- «Розраховано за токенами»: повна фінальна usage × тариф, зафіксований до
  виклику. Ця оцінка зменшує резерв, але не є підтвердженим рахунком API.
- «У резерві»: запит підготовлений/надісланий, завершення ще не зафіксоване.
- «Потребує звірки»: невідома вартість після збою, скасування чи неповної usage.
  Резерв збережений; повторний виклик не звільняє попередню суму.

Для грошового резерву враховуються повний UTF-8 розмір запиту +256 та весь
вихідний ліміт, із округленням угору до нанодолара. Активований токенний профіль
не зменшує цей грошовий запас. Це внутрішній евристичний контроль, а не гарантія
рахунку зовнішнього сервісу при зміні його тарифів або правил. Фактичне списання
понад резерв записується повністю та може заблокувати наступний виклик.

Venice DiEM показується окремо. USD=0 при позитивному DiEM не означає нульової
тарифної вартості: за повною usage використовується USD-еквівалент тарифу;
без неї резерв залишається. Local/Codex мають статус `unpriced`, usage та
невідому доларову ціну, а не вигаданий рахунок USD=0.

Після збою відкрийте «Історія викликів і звірка» → «Завантажити виклики».
Для `reserved`, `sent`, `unresolved` можна вказати підтверджену суму та джерело.
Звірка активного виклику заборонена файловим блокуванням; після завершення
або аварійного виходу процесу вона стає доступна. Нуль дозволений лише як
явна авторська звірка. Історія подій зберігається.

## Standalone CLI

Використовуйте один каталог обліку для узгодженого ліміту. Перед CLI зупиніть
застосунок, якщо він використовує цей каталог: CLI бере те саме кореневе
блокування, що й сервер та холодне резервне копіювання.

```powershell
./.venv/Scripts/python.exe -m storygen.billing.cli --data-dir data --scope cli:tests set --limit-usd 0.90 --run-limit-usd 0.20
./.venv/Scripts/python.exe -m storygen.billing.cli --data-dir data --scope cli:tests summary
```

Наступна зміна ліміту потребує `--expected-revision` із поточного summary.
Для ручного тарифу створіть JSON (ставки тут лише ілюстративні; перевірте їх
самостійно, а дату замініть на майбутню):

```json
{
  "provider": "venice",
  "model": "EXACT_MODEL_ID",
  "base_url": "https://api.venice.ai/api/v1",
  "input_per_million": "0.10",
  "output_per_million": "0.20",
  "request_usd": "0",
  "source": "Посилання на перевірений тариф або опис джерела",
  "expires_at": "2030-01-01T00:00:00Z"
}
```

```powershell
./.venv/Scripts/python.exe -m storygen.billing.cli --data-dir data --scope cli:tests tariff --file manual-tariff.json
./.venv/Scripts/python.exe -m storygen.evaluation.cli evaluate --case case.json --config evaluator.json --budget-data-dir data --budget-scope cli:tests --run-limit-usd 0.20
./.venv/Scripts/python.exe -m storygen.billing.cli --data-dir data --scope cli:tests calls
./.venv/Scripts/python.exe -m storygen.billing.cli --data-dir data --scope cli:tests reconcile --call-id CALL_ID --amount-usd 0.001 --source "Перевірено у кабінеті провайдера"
```

`calibrate` підтримує ті самі три бюджетні аргументи; усі повтори входять в один
ліміт запуску. Для cloud `--budget-scope` обов’язковий; для Local/Codex без нього
використовується `cli:evaluator`. `--dry-run` не створює ledger і не викликає API.
Ключі лишаються в `.env`, не в JSON тарифу чи ledger. Ledger зберігається в
SQLite schema 2 та входить у резервну копію й перевірку цілісності. Старі
виклики до запровадження обліку не отримують вигаданої історичної вартості.
