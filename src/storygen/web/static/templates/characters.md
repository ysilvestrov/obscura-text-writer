# Персонажі

Як користуватися шаблоном:
- Замініть приклади й текст у квадратних дужках; для кожного персонажа створіть окремий заголовок другого рівня з його ім’ям.
- У складі сцен використовуйте ті самі імена, що й у заголовках цього файла. Псевдоніми та зменшувальні форми автоматично не зіставляються.
- Після імпорту описи стануть початковими картками. Уже відредаговані картки повторний імпорт автоматично не перезаписує.
- Тут описуйте персонажів станом на початок історії. Нові знання, травми, зміни стосунків та інші майбутні події додавайте окремими відомостями після імпорту.
- У панелі «Доступність відомостей персонажів» оберіть «Від самого початку» для початкових відомостей, а для пізніших — «Починаючи зі сцени» та потрібну сцену. Звичайний напис про час у цьому файлі не встановлює цієї доступності: імпортовані описи спочатку мають статус «Час не перевірено».
