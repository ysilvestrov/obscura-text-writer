# План оповідання

Робоча назва: [Назва оповідання]
Задум: [Про що історія та що змінюється для головного персонажа.]

Як користуватися шаблоном:
- Замініть приклади й текст у квадратних дужках своїми даними; додайте потрібну кількість сцен.
- Зберігайте заголовки у форматі «Сцена N: Назва». Номери мають відповідати порядку читання.
- У рядку «Хто бере участь:» або «Персонажі:» пишіть імена через кому, точно як у заголовках файла персонажів. Для сцени без персонажів залиште цей рядок порожнім.
- День 1 — обраний вами початок відліку. Для переходу через північ указуйте новий день у полі «Кінець». Замість номера дня можна написати календарну дату.
- Час — час подій у світі твору. Для спогаду явно вкажіть день його подій; порядок сцен при цьому залишається порядком читання.
- Перевіряйте, чи вміщаються дорога, розмови, очікування та інші дії у відведений проміжок. Програма зберігає ці мітки в плані, але не обчислює тривалість і не перевіряє суперечності автоматично.
