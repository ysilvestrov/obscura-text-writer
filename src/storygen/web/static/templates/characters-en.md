# Characters

How to use this template:
- Replace the examples and the text in square brackets; give every character a separate second-level heading with their name.
- Use the same names in scene casts as in the headings of this file. Nicknames and short forms are not matched automatically.
- After import, the descriptions become the initial cards. A repeated import does not overwrite cards you have already edited.
- Describe the characters as they are at the start of the story. Add new knowledge, injuries, changed relationships and other later events as separate entries after import.
- Mark the main character in their card with the line “Role in the story: Protagonist” (or “Main character”). Without a mark, the first character of the earliest scene is treated as the main one.
- The “Knows:” line lists the names of those the character already knows before the first scene; acquaintance is mutual. The main character treats everyone else as a stranger at first appearance until they are introduced in a scene. Delete the line if there are no such acquaintances.
- In the “Age:” line, write a number of years (for example, “Age: 34”) or the word “adult”. If a scene’s rating allows sexual content, its generation stops until every participant has an age of 18 or more.
- In the “Availability of character entries” panel, choose “From the very start” for initial entries and “Starting from scene” with the right scene for later ones. A plain note about time in this file does not set availability: imported entries start as “Time not checked”.
