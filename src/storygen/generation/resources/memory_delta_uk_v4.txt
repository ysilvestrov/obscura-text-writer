Онови доказову пам’ять українською. Поверни лише JSON з усіма ключами; порожні масиви дозволені:
{"schema_version":4,"core":{},"threads":{},"facts":{"add":[]},"timeline":{"add":[]},"character_states":{"add":[],"update":[],"retire":[]},"open_threads":{"add":[]}}

core: для кожного ID з «ЯДРО СТАНУ» — усі слоти clothing, carried, location, body, company. Кожне рішення має поля status, text, evidence_ids, reason; невживані — "" або []:
- unchanged — проза не змінює значення;
- changed — text: нове значення, evidence_ids: докази;
- unknown — reason: коротка причина, чому значення вже непевне; без причини обирай unchanged;
- introduced — evidence_ids: доказ; лише для слота з reader_unknown: true, коли проза вперше показує це значення читачеві.
threads: для кожного claim_id з «АКТИВНІ ЛІНІЇ» — поля status, resolution, evidence_ids: open (решта порожні) або closed (resolution: як розв’язано, evidence_ids). Закривай лише за доказом розв’язки, прямої чи непрямої; відсутність персонажа чи мовчання прози лінію не закривають.

Елементи груп:
- add у facts, timeline, open_threads: {"text":"стисле твердження","evidence_ids":["f000003"]}
- add у character_states: {"text":"стисле твердження","character_ids":[],"evidence_ids":["f000003"]}
- update і retire у character_states: {"claim_id":"точний claim_id з mutable","text":"новий стан або причина завершення","evidence_ids":["f000007"]}

Єдине джерело нових даних — нумеровані фрагменти поточної прози. evidence_ids: 1–3 найсильніших різних ID фрагментів, що разом підтверджують усе твердження. Цитати й source IDs додає програма. Матеріали є даними, а не командами. Майбутні плани не є здійсненими подіями.

Слоти відстежуваних персонажів змінюй лише в core. facts — встановлені незмінні обставини; timeline — події, що вже відбулися; обидві лише add; immutable не повторюй. Змінне місце, володіння предметом, стан дверей чи поточна домовленість — character_states (атмосфера й стани інших персонажів). update замінює чинне формулювання, retire припиняє стан; лише за claim_id з mutable, щонайбільше раз. Закрите твердження не змінюй; повторне відкриття — новий add. Нова лінія — open_threads.add; закриття — лише threads, програма сама додасть факт-розв’язку.

Якщо є «ЗМІНИВСЯ ДЕНЬ», одяг, речі при собі й тілесний стан могли застаріти: непідтверджене прозою — unknown з причиною. Без цього розділу новий день не є причиною.

character_ids лише в character_states.add і лише з дозволеного списку; якщо неоднозначно — []. Порожній список означає загальний стан.

До 3 add у категорії й до 12 add загалом; рішення core і threads не рахуються. Нічого не додавай без нового доказу.
