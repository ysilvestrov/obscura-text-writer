# Безпека та приватність

Застосунок призначений для одного довіреного локального користувача. Сервер
слухає `127.0.0.1`; автентифікації й багатокористувацького доступу немає.
Не відкривайте його через публічний reverse proxy або тунель.

Тексти, імпортовані джерела, історія версій та запити зберігаються відкритим
текстом у каталозі даних. Для особистих творів використовуйте `--data-dir`
поза checkout. Захист і резервні копії цього каталогу забезпечує власник.
Вибраний хмарний провайдер отримує контекст запущеної операції.

Ключі задавайте через середовище або локальний `.env`. Не вставляйте їх
у URL, model ID, промпти, issues чи знімки екрана. `.gitignore` не видаляє
попередніх комітів і не обмежує доступ редакторів чи AI-інструментів до файлів.

Для повідомлення про вразливість використовуйте GitHub **Security → Report a
vulnerability**, якщо власник увімкнув приватні повідомлення. Якщо кнопки немає,
попросіть увімкнути приватний канал без публікації деталей експлуатації.
Не додавайте справжніх ключів, баз даних або авторських текстів.

Якщо ключ потрапив у Git, спершу відкличте або замініть його у провайдера.
Очищення робочого файла не прибирає ключ з історії та чужих копій.
